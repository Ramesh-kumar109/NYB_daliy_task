Hoisting

* Hoistng is a default behaviour of moving declaration of the top of the scope before the code execuite.
* this happen automatically during the memory creation phase brfore any code run actually

Hoisting Temporal dead zone

Let and const are hoisted but not intialized they sit in the Temporal Dead Zone(TDZ) until their declaration line runs, Asscessin them before that throw an error.

Function Declaration Hoisting

Entire function Declaration are Hoisting you can call them before they are define

Function Expression hoisting

A Function expression are not hoisted only the variable declaration is hoisited as(undefine) not the function

Arrow function Expression Hositing

An arrow function Expression Behave the same as function expression not hositing

Recursive Functions

A recursion function is a function that call itself to solve a problem by breaking it down into smaller sub-problems.
