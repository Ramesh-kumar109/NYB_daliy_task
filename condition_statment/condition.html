Condition Statement

Condition statements are used to perform different actions based on different conditions

  1. if statement
  2. if-else statement
  3. if-else-if -else statement
  4. Switch Statement

1.if statement

if statement is used to execute a block of code if a specified condition is true

2.if-else statement

if-else statement is used to execute one block of code if a condition is true, and another block if it is false

3.if-elseif-else statement

if-elseif-else statement is used to execute the block of code if a condition is false (or) it will move for elseif statement is used to block of code if the condition is ture otherwise else block will execute

4.Swtich Statement

Switch statement you compare one value against multiple possible cases and run the code matches
