Scope

* Scope where the variable are accessible in your code.

  1. Types of Scope
    • Global Scope
    • Function Scope
    • Block Scope

Global Scope

Global scope we declare outside function (or) block we can accessible everwhere

Function Sope

A function Scope (var,let const) we declare the variable in function block we can accessible form that function block only we can't access form the outside of function that is called function scope

Block scope

A block scope where the let and const variables are within if,for,while {} block only accessible with that block we cant access form the outside block
