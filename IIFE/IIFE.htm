IIFE-(Immediately Invoked Function Expression)

A IIFE is function that run the moment it's define without needing to be called separately

Closure

A function has inside the another function and inner function access the variable of outer function scope that is called closure

Pure Function

A pure function has Always return same inputs for the same output and its has no side effect

Impure Function

A impure function same input and varying the output it will changes in something outside itself
