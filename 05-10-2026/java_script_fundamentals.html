Variables

Variables are containers for storing data values.

  1. var
  2. let
  3. const

Primitive Data Types

A primitive datatype is it will store data in single values in single variables

    • Types of primitive datatype
      • String
      • Number
      • Boolean
      • Null
      • Undefined
      • Symbol
      • Bigint

Non-Primitive (or) Reference Data Types

Non primitive data is it will store multiple values are in single variable

  1. Types of reference datatypes
    • Array
    • Object
    • Function

Conversion methods

It converts one Datatype to another Datatype

  1. Implicit Conversion
  2. Explicit Conversion

Implicit Conversion it will convert the datatype automatically

Explicit Conversion it will convert the datatype manually
