Operators in JavaScript

1. Arithmetic Operators

Arithmetic operators are used to perform arithmetic on numbers (literals or variables). The arithmetic operators are:

  1. Addition (+)
  2. Subtraction (-)
  3. Multiplication (*)
  4. Division (/)
  5. Modulus (%)
  6. Increment (++)
  7. Decrement (--)

2. Assignment Operators

Assignment operators are used to assign values to JavaScript variables.

  1. =
  2. +=
  3. - =
  4. *=
  5. /=
  6. %=

3. Comparison Operators

Comparison operators are used in logical statements to determine equality or difference between variables or values.

  1. == (Equal)
  2. ===(Strictly Equal)
  3. != (Not Equal)
  4. !== (Strictly Not Equal)
  5. > (Greater Than)
  6. < (Less Than)
  7. >= (Greater Than or Equal)
  8. <= (Less Than or Equal)

4. Logical Operators

Logical operators are typically used with Boolean (logical) values; when they are, they return a Boolean value.

  1. && (Logical AND)
  2. || (Logical OR)
  3. ! (Logical NOT)

5. Ternary Operator

The conditional (ternary) operator is the only JavaScript operator that takes three operands. This operator is frequently used as a shortcut for the if statement.

6. Bitwise Operators

Bitwise operators work on bits and perform bit-by-bit operations.

  1. & (Bitwise AND)
  2. | (Bitwise OR)
  3. ^ (Bitwise XOR)
  4. ~ (Bitwise NOT)
  5. << (Left Shift)
  6. >> (Right Shift)

Template Literals

Template literals are string literals that allow embedded expressions. They are enclosed in backticks (`) instead of quotation marks.

Operators Precedence

Operators with higher precedence are evaluated before those with lower precedence.

ECMA Script

EMCA script is a standard specification that JavaScript is built on. Think of it as the rule book, and JavaScript is the actual language that implements those rules.
